# Technical Research

Define the decision and comparison criteria. Separate local repository evidence from external claims.

Prefer official documentation, specifications, release notes, source repositories, registries, and primary papers. Record version and date for unstable facts. Open sources rather than relying on search snippets, and fetch only relevant sections.

Return concise findings with source URLs near each claim, tradeoffs, a recommendation, and unresolved uncertainty. Never paste large copyrighted passages or raw HTML.
