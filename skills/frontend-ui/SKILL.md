# Frontend UI

Inspect the component system, tokens, routing, data flow, existing screenshots, and accessibility patterns. Reuse established primitives.

Define states before styling: loading, empty, error, success, disabled, focus, hover, reduced motion, small viewport, and long content. Keep keyboard navigation, semantic HTML, labels, focus order, contrast, and live announcements correct.

Verify with unit/component checks and a real browser where available. Inspect DOM, console, network failures, and screenshots at representative widths. Use an isolated browser profile and close owned sessions.
