# Second Brain

This vault is the human-readable interface to Pi Overdrive memory. It works as ordinary Markdown when Obsidian is closed.

Only notes whose frontmatter contains `memory: true` are considered by explicit `/memory sync`. Sync is mtime-based, local, and curated; it never imports API keys, credentials, raw transcripts, or every machine memory. OpenViking and Hindsight remain the machine-facing retrieval engines, while the local ledger records curation and provenance.

Useful areas are created as work appears. The project seed below documents Pi Overdrive; the templates keep decisions and lessons consistent.
