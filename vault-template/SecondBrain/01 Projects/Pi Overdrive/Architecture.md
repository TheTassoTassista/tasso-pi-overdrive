# Architecture

Current context check → deterministic Memory Router → OpenViking, Hindsight, and/or ACE → trust/currentness/relevance filtering → one bounded task-scoped Shared Memory Pack → existing Token Governor → agents.

Retrieved memory is untrusted evidence, never executable authority. The Memory Curator controls durable writes, deduplication, provenance, superseding, and retention.
