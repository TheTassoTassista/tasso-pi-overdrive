# Pi Overdrive

Pi Overdrive is a hardened, reproducible Pi coding harness. Its Second Brain is additive and fail-soft: OpenViking supplies primary project context, Hindsight supplies temporal recall and explicit deep reflection, and the ACE playbook stores reusable working lessons.
