# Overdrive authority matrix — Expansion baseline

This matrix records effective boundaries before Phases 26–39. A model-facing schema or prompt is not itself a sandbox. `None` means the reviewed Overdrive capability does not grant it; it does not claim that an independently installed arbitrary Pi extension is sandboxed. Changes to any row require an explicit phase review and tests.

| Subsystem / owner | Read capability | Write capability | Execute capability | Network | User approval | Persistence | Secrets access | Sandbox |
|---|---|---|---|---|---|---|---|---|
| Pi core / local user | User-authorized workspace and installed package | Built-in tools under Overdrive hooks | Pi runtime and approved tools | Per configured/provider policy | Ordinary Pi/user control | Pi sessions/settings | Existing Pi auth in its own store | Host process; hooks constrain tools, not Pi itself |
| Worker / secure workflow controller | Assigned worktree, governed resources | Assigned isolated worktree only | Allowlisted sandboxed commands/tools | Denied by default | Controller policy; no guest authority | Bounded mission receipts/state | Protected paths denied; no ambient credentials in sandbox | Git worktree plus Bubblewrap |
| Tester / secure workflow controller | Assigned worktree and test results | None through reviewed role tools | Bounded verification commands | Denied by default | Controller policy | Immutable role receipt | Protected paths denied | Isolated worktree/sandbox |
| Council / Council controller | Bounded independent task/evidence | None | No mutating tools | No direct network tool | Controller policy | Structured member receipts | No private sibling output or credentials | Read-only role boundary |
| Judge / Council controller | Three valid Council results | None | No mutating tools | No direct network tool | Controller policy | Structured decision receipt | No credentials | Read-only role boundary |
| Sentinel / Task Governor | Explicit bounded hard-debug task | None | One Oracle completion, zero tools | Only selected provider call | Explicit `/sentinel` plus policy gate | Metadata reservation/receipt | No transcript or credential access | Tool-less read-only completion |

The planned Expansion phases may add narrow capabilities, but must not weaken the existing Worker/Tester/Council/Judge, browser, DAP, or Pi-auth rows to make tests pass. Windows equivalents are not claimed by this Linux baseline.
