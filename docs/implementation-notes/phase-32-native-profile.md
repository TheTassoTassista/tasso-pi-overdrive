# Phase 32 — Native Core / Fast Paths: measured, not added

The new `phase32-owned-cpu.mjs` fixture profiles the current Expansion control path locally, including a 1,645-candidate registry with one selected model, a 445-model catalog, and representative task/tool/context/artifact/prewalk operations. Wall time and process CPU are reported separately. On 2026-09-24, the measured per-operation wall means were: Task Governor 0.098 ms, Tool Governor 0.174 ms, registry 1.282 ms, catalog normalization 0.263 ms, Context Fit 0.019 ms, artifact sanitization 0.277 ms, SHA-256 of 1 MiB via Node's native crypto 0.589 ms, eligible prewalk policy 0.085 ms, and actual local 1.1 MiB catalog file read/parse 6.078 ms. These are one-host fixture measurements, not population performance claims; CPU includes Node's native runtime and file parsing.

Existing real-Pi deterministic local-provider benchmarks were rerun for Task Governor, Tool Governor, ResourceFS, SmartRead, Artifact Store, Context Governor, Git ResourceFS, local prewalk, and Provider Registry: all nine PASS, with zero paid/external provider calls. Their total process runtimes were 1.1–4.0 seconds per whole benchmark suite, **not** per-operation JS CPU attribution. Separate 20-run local startup controls had medians of 3.91 ms for Node, 1.24 ms for Git, and 255.15 ms for Pi `--version`. The existing AST/edit benchmarks include native ast-grep and LSP subprocess latency, which is not counted as Overdrive-owned JS CPU. Git parsing remains behind the hardened native Git runner, not an identified JS parser hot path; ResourceFS/SmartRead/storage I/O likewise cannot be attributed to JS merely from end-to-end elapsed time.

The pinned OMP reference at `a1b3b83a7fb8460445f2f5995a6aa56047bd44c7` was inspected read-only. Its MIT `pi-walker` is a parallel filesystem walker (globset/ignore/rayon) and its `pi-natives` is a larger N-API package combining many unrelated facilities. Neither is justified for the measured low-volume registry/control decisions, and OMP itself was not run as a numeric comparator. No OMP source was copied, no Rust binary/build chain/dependency was added, and no existing fallback changed.

Decision: **MEASURED / NOT ADDED**. The highest local cost, reading/parsing the optional catalog, is about 6 ms per read on this host and is not a proven real-task bottleneck. A native rewrite would add deployment and semantic-equivalence complexity with no demonstrated material gain. A single full-gate run during profiling observed 497/498 before syntax, but the next focused test run and full gate both returned 498/498; the first failure identity was not retained in truncated output. This isolated observation is recorded, not “fixed” speculatively. The final authoritative gate with the documented LSP runtime passes 498/498, syntax, TypeScript, package validation. Extra monetary cost €0.
