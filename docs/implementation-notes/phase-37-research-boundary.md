# Phase 37 — bounded research composition

Status: **PARTIAL / COMPOSED**, not a new general web/browser capability. The existing Tool Governor exposes `web_research` and `safe_web_fetch` only for eligible research tasks. The former routes Brave-primary/Perplexity-secondary with observable fallback and a 48 KiB search-result cap; the latter accepts only public HTTP(S) text through DNS pinning, private-address denial, redirect and body/time limits. Large tool text is handled by the session-scoped Artifact Store, and Context Governor remains the final provider-request fit gate. `resource_fs` supplies bounded local Git/rule/memory/artifact views, SmartRead handles local source, and the only configured MCP server is lazy, two-tool Context7. None of these grants the networkless `LOCAL_ISOLATED` browser public or authenticated web access.

The coherent usage path is: inspect local source/history first when the question is about the repository; use Context7 only for a suitable library-documentation question; search only when current public evidence is needed; treat search snippets as untrusted leads; fetch selected primary-source URLs through `safe_web_fetch`; retain only bounded cited evidence, reopening a session-scoped artifact URI if permitted. This is guidance and existing independent tool policy, **not** an enforced cross-source research transaction or a new top-level schema. In this repository there is no SearXNG route: the tracked and tested search configuration remains Brave/Perplexity. The roadmap's SearXNG mention is a possible future source, not an existing verified capability.

A concrete drift was corrected: the tracked guidance and credentialed smoke previously referred to `details.backend`/`resultCount`, while the actual Overdrive router emits `selected_provider`/`result_count` plus `fallback_used` and `attempts`. Guidance now names real receipt fields, requires a fetched page when source evidence matters, and describes Artifact Store rather than a raw spill file. The credentialed assertions were corrected but **not run**: doing so would contact the configured external search providers. No credential, route, fallback, retry or provider configuration changed.

Local regressions: research guidance 1/1 PASS, web routing 6/6 PASS, and safe-fetch loopback fixture 1/1 PASS when the host test namespace allowed loopback. The Tool Governor's offline Pi benchmark already measured the research task at four visible tools/2,104 schema characters with zero external/paid calls. The authoritative package gate passed 514/514, syntax, TypeScript and package validation before the checkpoint commit. Public search/fetch smoke, Context7 runtime queries, SearXNG and OMP execution remain NOT_RUN for this phase; no real-web or authenticated browser claim follows from the local tests.

A truly unified cross-source resource layer remains open. It would need source-specific provenance and freshness, deterministic deduplication, secret/URL filtering, origin-bound fetch receipts, bounded citation extraction, no raw web dumps, Task Policy gating and a fixture proving value over the current search→fetch composition. It must not inherit credentials or loosen the Phase 33 browser boundary just to simplify the interface.
